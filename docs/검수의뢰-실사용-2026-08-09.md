## 1. 제품 개요 (검수자용 최소 컨텍스트)

- VS Code 확장. 부트캠프 수강생이 실습 폴더에서 기록을 켜면 **저장(Ctrl+S)마다 자동 git 커밋**(20초 디바운스)으로 스냅샷을 남긴다.
- 하루 끝에 **복기 화면**(웹뷰): 수업 시간표(파트) 위에 씬(파일별 변경 묶음)·필기([HH:mm] 타임라인)·🧹 일괄작업을 시간순 배치. ♻️(지웠다 재생성)는 전후 비교 1클릭.
- **TIL 원자재 내보내기**: 하루치(배운 것 메모+필기+코드 diff)를 md 한 파일로 → AI에 붙여 TIL 초안.
- 서버·계정 없음. 데이터 = 로컬 git 커밋 + `필기/*.md` + 날짜별 JSON(복기노트·마크·한줄정리).
- 코드: `extension.js`(VS Code 글루 326줄) + `lib/` 12모듈(순수 Node, 테스트 27종). 총 ~2,000줄.

## 2. 실사용 재현 방법 (이 검수의 실측 근거)

lib 모듈이 vscode 비의존이라 **확장의 실제 코드 경로를 그대로** 스크래치 git 저장소에 돌렸다:
- React 블로그 실습 하루를 커밋 타임스탬프(09:05~17:55, 14커밋)로 재현 — 생성·수정·삭제→재생성(♻️)·멀티파일 커밋·12파일 노이즈 커밋 포함.
- 필기 타임라인 5줄, 파트별 「배운 것」 2건, ★ 마크 1건 주입.
- `commitsForDate → buildDay → attachSceneSigs → render`(복기 HTML), `sceneDiff → buildExportMd`(내보내기 md)를 실행하고 HTML은 headless Chrome으로 시각 확인.
- 재현 스크립트·산출물: 세션 스크래치(`scratchpad/drive.js`, `story.html`, `export.md`) — 휘발성.

## 3. 잘 되는 것 (실측 확인 — 재검증에 시간 쓰지 말 것)

- 씬 묶음(같은 파트·같은 파일, 3분 텀 초과 시 새 단락), ♻️ 감지(reworkSha=삭제 커밋), 파트 넘긴 재생성도 잡음.
- 필기 교차 배치·3분 이내 연속 줄 단락 뭉침, BOM/CRLF 호환.
- 🧹 노이즈 뭉침(≥10파일), +n/−n(numstat), 첫 변경 시그니처(hunk 헤더), 미니맵·파일 칩·★ 마크·종료 카드 렌더 정상.
- 사고 방어: remote 연결 저장소 1회 확인, 중첩 git repo 경고, node_modules 자동 .gitignore, 기록 on/off 기기별(globalState — 설정 파일로 전파 안 됨), 구버전 autoRecord 확인 후 반영.
- 종료 flush(2.5/4초 타임아웃, 실패 시 다음 커밋에 흡수), 커밋 실패 표면화(상태바+알림+로그).

## 4. 발견한 문제 (실측·코드 근거 포함 — 적대 검수의 공격 지점)

### A. 데이터가 사용자 몰래 빠지는 급 (심각 후보)

**A1. 복기 화면을 한 번 열면, 이후 적은 필기는 복기·내보내기에서 증발**
- `lib/reviewData.js:32` `loadNotes` — 복기노트 JSON이 있으면 타임라인 md를 무시. 첫 열람 때 1회만 시드.
- 실측: 시드 후 타임라인에 `[17:10]` 줄 추가 → loadNotes 재호출 결과에 **미반영**.
- 시나리오: 점심에 궁금해서 복기 탭을 열어봄 → 오후 필기 전부가 복기 화면·TIL 원자재에 안 나옴. md 파일엔 남지만 사용자는 모른다.

**A2. 멀티파일 커밋에서 비대표 파일이 완전히 증발**
- `lib/model.js:93-100` — 커밋당 대표 파일 1개만 씬이 되고 나머지는 extras(툴팁 표시용).
- 실측: 11:10 커밋(App.jsx 수정 + PostForm.jsx 생성) → PostForm 생성이 씬 없음, **export.md에 diff 자체가 부재**(`sceneDiff`가 `-- 대표파일`만). 파일 칩은 뜨는데 씬 0개라 클릭하면 빈 화면.
- 저장을 미루다 한 번에 저장하는 초보 습관에서 빈발 조건.

**A3. ♻️ 씬의 내보내기 diff가 화면과 다름 — 제품의 1등 순간이 TIL 원자재에서 소실**
- 화면: `extension.js:176` `sceneDiff(repo, s.reworkSha || s.firstSha, ...)` = 지우기 전판↔새판 비교.
- 내보내기: `extension.js:190` `sceneDiff(repo, it.firstSha, ...)` — reworkSha 미사용.
- 실측: export.md의 ♻️ 씬이 `new file mode` + 전체 `+` 줄로만 출력. 트러블슈팅 재료(전후 비교)가 프롬프트가 강조하는 바로 그 지점에서 빠진다. (직전 🔴 씬의 삭제 diff로 간접 복원은 가능)

**A4. 필기 줄을 수정하면 타임라인이 오염**
- `lib/notes.js:61-71` 멀티셋 diff — 기존 줄의 오타 수정 = "새 줄"로 판정.
- 실측: `props는 단방향` → `props는 단방향 (부모→자식)` 수정 저장 → 타임라인에 `[23:18] props는 단방향 (부모→자식)` **현재 시각으로 재기록**(원 줄도 잔존). 복기에 같은 내용이 두 시각으로 중복 + 시각 의미 왜곡.

### B. 비일관·경계 조건

- **B1.** 사이드바 날짜 목록(`recentDays`)은 `--author=내 이메일` 필터, 복기 화면(`commitsForDate`)은 무필터 — 클론한 저장소에서 upstream 커밋이 그 날짜 복기에 섞인다(`lib/git.js:109` vs `:141`).
- **B2.** 🧹 노이즈 커밋 안의 삭제는 `deletedSoFar`에 안 들어감(`model.js:40-53` 분리 후 `:93` codeCommits만 순회) — 대량 삭제 후 재생성이면 ♻️ 미감지.
- **B3.** `archiveDir`가 잘못된 경로면 **조용히** repo 루트로 폴백(`extension.js:66`) — 사용자는 아카이브에 쌓인다고 믿는다.
- **B4.** export diff 예산(3000줄) 검사가 추가 "전"이라 마지막 씬이 예산을 최대 300줄 초과 가능(`exportMd.js:52-54`). `new file mode`/`deleted file mode` 줄이 cleanDiff에서 안 걸러짐(원자재 노이즈).
- **B5.** 상태바 `⏺ 기록중 · 14:32 스냅샷`이 다음 커밋까지 계속 그 시각으로 유지 — "지금도 기록 중인가?" 오독 여지.
- **B6.** 주말·휴일 필기 자동생성 제외는 있는데 **보강 토요일**(영업일 추가) 방향이 없음 — 수동 「오늘 필기 열기」(force)로만 우회.
- **B7.** 필기 타임라인 기록(`trackSave`)은 **오늘 날짜 파일만** 처리 — 어제 필기를 보충해도 타임라인엔 안 쌓임(복기노트 JSON 편집으로는 가능).

### C. 온보딩·마찰 (경미)

- **C1.** `blocks` 기본값이 특정 캠프 시간표 — 일반 사용자는 첫날 설정 필수인데, 안 바꿔도 동작은 해서 파트 라벨이 조용히 어긋난다.
- **C2.** TIL 프롬프트 동봉이 opt-in 설정(`includeTilPrompt`) — 설정 화면을 찾아가야 하고, 워크스루 문구로만 안내.
- **C3.** 구버전 vsix 7개가 로컬에 잔존(0.2.0~0.7.0) — 마켓 설치 전환 후 정리 안내 없음(사용자 기기 문제, 제품 문제는 아님).
- **C4.** 알려진 한계(README 명시): 터미널 명령 미기록, 저장 사이 흔적 소실, 멀티루트 첫 폴더만.
