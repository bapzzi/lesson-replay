## 필기는 한 줄이면 충분

필기 파일에는 수업 시간표(파트)별 제목이 미리 깔려 있습니다. 강사 설명이 나오면 지금 파트 아래에 **한 줄**만 적고 저장하세요.

```
## 파트2 (10:15~11:30)
map 돌릴 때 key 꼭 넣기. index를 key로 쓰면 왜 안 되는지
```

저장하면 적은 시각이 함께 기록되어, 저녁 복기 화면에서 **그 시각의 코드 사이에 필기가 끼어듭니다.** 어떤 설명이 어떤 코드였는지 이어서 볼 수 있습니다.

- 평일 아침엔 필기 파일이 자동 생성됩니다
- 시간표가 다르면 설정(`Ctrl+,`)에서 `lessonReplay.blocks`를 내 수업 시간으로 바꾸세요
