## 켜면 무슨 일이 생기나

코드를 저장(`Ctrl+S`)할 때마다 스냅샷이 자동으로 남습니다. 연속 저장은 20초 단위로 하나로 묶입니다.

켜진 뒤에는 **왼쪽 아래 상태바**가 계기판입니다:

| 표시 | 뜻 |
|---|---|
| `⏺ 수업 기록중` | 켜짐 — 그냥 코딩하면 됩니다 |
| `⏺ 기록중 · 14:32 스냅샷` | 방금 저장분이 기록됐다는 확인 |
| `⚠ 기록 실패` | 문제 발생 — 알림의 "로그 보기"로 원인 확인 |

git 저장소가 아니면 사이드바의 **[git 저장소 만들기]** 버튼 한 번이면 준비됩니다. 기록은 전부 이 폴더 안에만 남고 어떤 서버로도 전송되지 않습니다.
