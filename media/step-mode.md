## 시간표가 있나요?

**시간표가 있는 수업**(부트캠프·학원·대학 강의)이면 시간표를 넣어 두세요. 복기 화면과 필기 틀이 파트(1교시, 2교시 …)로 나뉩니다.

```
"lessonReplay.blocks": ["09:00-10:30", "10:40-12:00", "13:00-15:00"]
```

**혼자 공부**하거나 시간이 매일 다르면 **자유 학습**을 고르세요. 시간표 없이, 30분 넘게 쉰 지점마다 「세션 1·2·3」으로 자동으로 나눕니다. 쉬는 기준은 `lessonReplay.sessionGapMinutes`에서 바꿀 수 있습니다.

나중에 언제든 명령 팔레트(`Ctrl+Shift+P`)의 「수업 리플레이: 시간표 쓰기」 / 「자동 세션 쓰기」로 바꿀 수 있습니다.
